# Button

An action, or a link styled as one.

- `variant`: `primary` for the one main action on a screen, `secondary` (the default) for the rest, `ghost` for a quiet
  action inside a row or a card's header.
- `size="sm"` inside rows and card headers.
- `href` makes it a link: use it to go to another screen, `onClick` to do something here.
