# Example

A small design system for trying the kit: three components on a handful of tokens. It is written as any project's
would be; nothing in the kit knows its names.

## Rules

- **One accent action a screen.** The primary button is the thing the screen is for; the rest are secondary or ghost.
- **Colour follows meaning.** Positive is done or passing, warning is what needs attention soon; neither is decoration.
- **Space in steps of 4.** Components use the spacing tokens; a screen's own layout may use its own.
- **Type in three styles.** `text-title` once a screen, `text-body` for everything else, `text-code` for ids and counts.
